# Goodreads Hybrid Recommendation System

A deep-learning book recommendation system built with PyTorch that combines Neural Matrix Factorization (NeuMF) with semantic book representations generated by a pretrained Sentence Transformer.

The project compares a collaborative-filtering baseline against a hybrid architecture that combines user/item interaction embeddings with content-based book representations.

## Highlights

- Neural Collaborative Filtering with NeuMF
- Hybrid recommendation architecture
- Sentence Transformer book representations
- Implicit-feedback training with negative sampling
- Top-K recommendation evaluation
- HR@10 and NDCG@10 metrics
- GPU-compatible PyTorch training
- Goodreads interaction data preprocessing
- Baseline vs. hybrid model comparison

## Models

### NeuMF Baseline

The baseline uses user and item IDs to learn collaborative representations from historical interactions.

### Hybrid NeuMF

The hybrid model extends NeuMF with pretrained semantic representations of books. The semantic representation is generated from book metadata using `all-MiniLM-L6-v2` and combined with the collaborative representations before the final prediction layer.

## Dataset

The project uses Goodreads book-review interaction data.

The raw dataset is intentionally not included in this repository because of its size. Place the required source files under:

```text
data/
├── raw/
└── processed/
```

The notebook performs the preprocessing and creates the interaction data used by the models.

## Evaluation

The notebook evaluates recommendations using:

- **HR@10** — whether the held-out positive item appears in the top 10 recommendations.
- **NDCG@10** — ranking quality of the relevant item within the top 10.

The current notebook preserves the original experiment and its recorded benchmark outputs. The evaluation protocol is documented in the notebook and should be considered when interpreting the reported metrics.

## Reported Results

The original experiment produced the following recorded HR@10 results:

| Model | HR@10 |
|---|---:|
| NeuMF Baseline | 64.16% |
| Hybrid NeuMF | 71.72% |

The hybrid experiment therefore showed a recorded improvement of 7.56 percentage points over the baseline under the notebook's original evaluation setup.

These numbers are preserved from the original experiment rather than presented as a newly reproduced benchmark.

## Installation

Python 3.10+ is recommended.

```bash
git clone https://github.com/YOUR_USERNAME/goodreads-hybrid-recommender.git
cd goodreads-hybrid-recommender

python -m venv .venv
```

Activate the environment.

Linux/macOS:

```bash
source .venv/bin/activate
```

Windows:

```powershell
.venv\Scripts\activate
```

Install dependencies:

```bash
pip install -r requirements.txt
```

For GPU training, install the PyTorch build appropriate for your CUDA version from the official PyTorch installation instructions.

## Running the Project

Start Jupyter:

```bash
jupyter notebook
```

Open:

```text
Goodreads_Hybrid_Recommender_Portfolio_NoComments.ipynb
```

Run the notebook from the data-loading section through the final evaluation section.

Because the Goodreads dataset and transformer embeddings are large, runtime and memory requirements depend on the available CPU, RAM, storage, and GPU.

## Reproducibility

The project uses a fixed random seed for the main experiment. Exact results can still vary across hardware, PyTorch/CUDA versions, and execution environments.

For a strict experimental comparison, evaluation candidates should be generated once and reused across models and checkpoints, and model selection should use a validation set rather than the final test set.

## Engineering Notes

The repository intentionally keeps the original experiment's benchmark methodology so that the recorded results remain comparable with the original notebook.

For a production or publication-grade experiment, the next improvements would be:

- temporal train/validation/test splitting
- fixed evaluation candidates
- validation-based early stopping
- explicit cold-start evaluation
- dynamic negative sampling
- automated tests for metrics and sampling
- separating reusable Python modules from the notebook
